# CampusConnect — College Club Event Management

A responsive college club event management website built with **HTML, CSS and vanilla JavaScript**.

## Features

### Student side
- Modern responsive home page
- Club introduction
- Featured event
- Upcoming events
- Event cards with name, date/time, venue and description
- Search events by name/description
- Category filter
- Registration form with validation
- Registration data saved using browser localStorage

### Admin side
- Dashboard statistics
- Add event
- Edit event
- Delete event
- Mark an event as featured
- View registered students
- Search registrations
- Filter registrations by event
- Data persistence using localStorage

## Run locally

No installation or backend is required.

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Click **Admin** in the navigation to open the dashboard.

For the best development workflow, use VS Code + Live Server.

## Demo flow

1. Open `index.html`.
2. Search/filter events.
3. Register for CodeSprint 2026.
4. Open Admin Dashboard.
5. Go to Registrations and show the submitted student.
6. Go to Manage Events and demonstrate Add/Edit/Delete.
7. Refresh the browser to demonstrate localStorage persistence.

## Important note

This is a frontend recruitment-task implementation. `localStorage` is used as a mock database. For a production deployment, connect the forms and admin dashboard to a backend/database and add real authentication.
